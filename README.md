🛣️ Sistema de Rota

O Bus Farm utiliza uma rota composta por 13 checkpoints.

A distância entre os pontos é calculada automaticamente para controlar o deslocamento do ônibus.

Rota

Parada 01 → Parada 02 → Parada 03 → Parada 04 → Parada 05 → Parada 06 → Parada 07 → Parada 08 → Parada 09 → Parada 10 → Parada 11 → Parada 12 → Parada 13

A corrida é contabilizada somente após a conclusão da 13ª parada.

🚌 Verificação do Ônibus

O HUB verifica se o personagem está dentro do ônibus antes de iniciar o deslocamento.

Durante o Farm, essa verificação continua ativa.

🔄 ROTA1

O sistema seleciona automaticamente a ROTA1 através da interface de trabalho da experiência.

Após completar a rota, a seleção pode ser realizada novamente para iniciar o próximo ciclo.

🛡️ Anti-AFK

O HUB possui um sistema Anti-AFK para reduzir desconexões causadas por inatividade.

O sistema realiza ações periódicas e responde ao evento de inatividade do jogador.
